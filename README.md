This entry features a comprehensive one-page newspaper front page summing up the world news of Wednesday, 18 November 2026. Hand-drawn entirely with Python Imaging Library (PIL) using DejaVu fonts without any generated images or text, the front page encapsulates 54 stories across 7 regions within 16 drawn panels, accompanied by a UTC timeline, a numbers strip, a world map, a 38-item index, and a date-check footer.

## Run it

To generate and output the entry image:

```bash
mkdir -p /output
export MAKEFUN_OUTPUT_DIR=/output
python3 main.py
```
